# SDY гишүүний PWA

Гар утасны хөтөч болон нүүр дэлгэцэд суулгасан апп ижил сервер, session,
байгууллагын role/permission, PostgreSQL RLS-ийг ашиглана.

## Хэрэглэгчийн урсгал

1. `https://e-sdy.mn/member` рүү орж eID Mongolia-аар нэвтэрнэ.
2. Харьяалалгүй хүн Дархан-Уул аймаг болон түүний Дархан, Орхон, Шарын гол,
   Хонгор сумын дөрвөн дэд байгууллагаас сонгож хүсэлт илгээнэ.
   Хүлээгдэж буй хүсэлт нь байгууллагын мэдээлэл унших эрх олгохгүй.
3. Тухайн салбарын manager/admin **Элсэх хүсэлтүүд** хэсгээс батлах эсвэл
   татгалзана. `membership.manage` нь role өөрчлөх админы эрх олгохгүй.
4. Батлагдсан гишүүн **Салбар руу орох** товчоор идэвхтэй салбараа сонгоно.
5. **Арга хэмжээ** хэсгээс бүртгүүлнэ. Зохион байгуулагч 5 минут хүчинтэй QR
   гаргана; утасны камераар уншуулж **Би ирсэн — батлах** дарна. QR унших
   мөчид бүртгэлгүй бол багтаамжийн шалгалттайгаар эхлээд бүртгүүлнэ.
6. **Ирц** хэсэгт хувийн оролцоо, онооны нийлбэр болон өөрчлөлтийн түүхээ харна.
7. **Хураамж** хэсэгт тухайн сарын ногдуулалт, үлдэгдэл, банкны заавар байна.
   Гишүүн шилжүүлгээ хийсний дараа банкны гүйлгээний дугаараа мэдээлнэ.
   Санхүүгийн ажилтан хуулгатай тулган баталсны дараа төлсөнд тооцно.

QR холбоосын код URL-ийн fragment дотор байдаг; серверийн URL логт очихгүй.
Нэвтрэх шаардлагатай үед ижил хөтчийн түр session storage-д 5 минут хадгална.
eID апп өөр хөтөч нээсэн, storage хаалттай эсвэл QR хугацаа дууссан бол
нэвтэрсний дараа шинэ QR уншуулна. QR нь тухайн мөчид хүчинтэй кодыг
мэдэж байгааг шалгана; байршил, нүүр танилт эсвэл биечлэн ирснийг дангаараа
нотлох хэрэгсэл биш. Зохион байгуулагч ирцийг шалгаж залруулж чадна.

## Утсанд суулгах

- Android Chrome: сайтад орж **Апп суулгах**, эсвэл хөтчийн цэсний
  **Install app / Add to Home screen** үйлдлийг сонгоно.
- iPhone Safari: **Share → Add to Home Screen**.

HTTPS шаардлагатай. Manifest `id=/`, `start_url=/member`, `display=standalone`.
Доод цэс нь Нүүр, Арга хэмжээ, Ирц, Хураамж, Миний бүртгэл. Салбарт
хараахан элсээгүй хүнд Нүүр болон Миний бүртгэл байна.

Сүлжээгүй үед хувийн мэдээлэл, ирц, төлөлт хадгалахгүй. Дахин холбогдох
мэдэгдэл гарна. API хариу болон нэвтэрсэн хуудсыг service worker кэшлэхгүй.
Ирц ба төлбөр серверт амжилттай хадгалагдсан үед л баталгаажсан гэж харуулна.

## Салбарын тохиргоо

- Manager/admin арга хэмжээ үүсгэхдээ оноог `0–100000` хооронд тохируулна.
  Анхдагч 0; ирц батлагдсан хүний онооны хэмжээг тухайн event дээр өөрчлөхгүй.
  Ирцийн залруулга нь нэмэх/хасах бичилт үүсгэж түүхийг хадгална.
- `membership.finance` анхдагчаар зөвхөн admin-д өгөгдөнө. Admin эрхийн
  удирдлагаар санхүү хариуцсан хүнд тусгайлан олгож болно. Manager-т
  санхүүгийн эрх автоматаар очихгүй.
- **Хураамжийн санхүү** хэсгээс сарын дүн, банк, данс, эзэмшигч, төлөх өдрийг
  тохируулна. Өдөр 1–28, мөнгөн дүн бүхэл төгрөг. Тохируулах хүртэл идэвхгүй.
- Сонгосон сарын хураамжийг идэвхтэй гишүүнчлэлтэй хүмүүст нэг удаа ногдуулна.
  Идэвхгүй болгосон хүний өмнөх ногдуулалт, төлөлтийн түүх хадгалагдана.
  Давтан дарахад өмнөх ногдуулалтыг давхар үүсгэхгүй. Элссэн сарын хувьчилсан
  тооцоо, урьдчилсан төлөлт, автомат сарын ажлыг энэ хувилбар хийхгүй.
- Хэсэгчлэн төлөлт, батлах/татгалзах, баталгаажуулалтыг буцаах, үлдэгдлээс
  чөлөөлөх боломжтой. Шалтгаан шаардлагатай. Баталгаажуулалтыг буцаах нь
  бүртгэлийн залруулга; банкны буцаан олголт хийхгүй.
- Оролцооны тайлан нь идэвхтэй салбарын, сонгосон сард эхэлсэн арга хэмжээг
  Улаанбаатарын цагаар тооцно. Санхүүгийн сарын тайлан нь ногдуулсан сараар.

Төлбөрийн provider холбоогүй: банкны шилжүүлгийг хүн тулгаж батална. QPay
зэрэг үйлчилгээний гэрээ, түлхүүр, хүлээн авагчийн данс батлагдсаны дараа
серверийн баталгаажуулалттай payment callback нэмнэ. Push мэдэгдэл, төвийн
салбар дамнасан нэгтгэл болон үндсэн салбар шилжүүлэх дүрэм дараагийн ажил.

## Шинэчлэлт ба салбаруудад идэвхжүүлэх

Энэ нь байгаа deployment-ийн шинэчлэлт. Шинэ identity үүсгэхгүй.
Салбарын бүтцийг `deploy/scripts/sdy-darkhan-topology.sql`-аар эхлээд dry-run,
дараа apply хийнэ. Одоогийн Дархан-Уулын админыг дөрвөн дэд байгууллагад
хариуцуулна. Бусад байгууллагыг suspend хийнэ; устгах нь операторын хоёр
админы баталгаа, 30 хоногийн одоогийн дарааллаар тусдаа шийдэгдэнэ.
Хүмүүс, personal workspace хэвээр үлдэнэ.

1. Одоогийн DB, `.env`, compose, brand файлын хамгаалагдсан backup авна.
2. Баталгаажсан image-ээр core migration 110 хүртэл шинэчилж API-г асаана.
   Startup нь Events schema 3, Membership schema 1-ийг ажиллуулна.
3. Оператор сервер дээр эхлээд шалгана:

   ```sh
   docker exec sdy_backend /app/sdy-provision
   ```

4. Дархан-Уул + дөрвөн сумын таван идэвхтэй байгууллага, суулгалтууд зөв бол хэрэгжүүлнэ:

   ```sh
   docker exec sdy_backend /app/sdy-provision -apply
   ```

   Команд Дархан-Уул болон нэрлэсэн дөрвөн хүүхдийн parent холбоосыг шалгаад
   зөвхөн энэ таван байгууллагыг элсэлтийн жагсаалтад нийтэлж, Events 1.1.0,
   Membership 1.0.1-ийг суулгана. Бүтэц дутуу/өөр бол татгалзана. Personal workspace,
   салбарын зориуд унтраасан апп, тогтоосон хувилбарын pin-д хүрэхгүй.
   Дахин ажиллуулахад одоогийн суулгалтыг давтахгүй.
5. API-г restart хийж идэвхтэй кэшүүдийг шинэчилнэ. `/ready`, manifest,
   таван байгууллагын суулгалт, RLS, manager/member эрхийг шалгана.

Rollback хийхдээ зөвхөн хуучин image асааж өгөгдөл устгахгүй; нэмсэн багана,
table хуучин хувилбарт саад болохгүй. Шинэ хувилбараар бодит төлөлт/ирц
орсон бол DB backup-ийг шууд сэргээх нь тэдгээрийг алдах тул эхлээд тусад нь
хадгалж, ялгааг тулгана.

## Баталгаажуулах тест

- Backend: бодит PostgreSQL RLS, session, installer бүхий элсэлт → QR → оноо
  → сарын хураамж → санхүүгийн баталгаажуулалт.
- Зэрэг ирсэн бүртгэл багтаамж хэтрүүлэхгүй; давтан QR давхар оноо өгөхгүй;
  зэрэгцээ төлөлт батлахад хураамжийн дүнгээс хэтрэхгүй.
- Гишүүн өөр хүний төлөлт харахгүй, manager role өөрчлөхгүй,
  `membership.finance`-гүй хүн төлөлт батлахгүй.
- Playwright: 390×844 утасны дэлгэц, аймаг + дөрвөн сумын сонголт, менежерийн хүсэлт,
  QR ирц, хувийн оноо, төлбөр мэдээлэх, manifest ба offline нөхцөл.
  Хөтчийн тестүүд API fixture ашиглана; backend тестүүд жинхэнэ DB ашиглана.
- eID Mongolia-ийн бодит утасны харилцан үйлдэл, Android/iPhone дээр
  суулгах эцсийн ажиллагааг төхөөрөмж дээр тусад нь хүлээн авна.

Бодит төхөөрөмжийн шалгах дараалал, менежер/санхүүгийн томилгоо болон
хураамж, онооны тохиргоонд хэрэгтэй мэдээлэл: [SDY туршилтын хүлээн авалт](SDY_PILOT.md).

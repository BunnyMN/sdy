## Нэмсэн шалгалт

[transfers_test.go](../backend/db/migrations/transfers_test.go) нь mock ашиглахгүй,
жинхэнэ PostgreSQL дээр `gerege_nexus_tenant` эрхээр шилжилтийн SQL
функцүүдийг дуудна. Тест бүр тусдаа UUID-тай өгөгдөл үүсгэж, дуусахад цэвэрлэнэ.

- Нэг салбар руу зэрэг илгээсэн хоёр хүсэлт ижил хүсэлтийн ID буцаана.
- Өөр хоёр салбар руу зэрэг илгээсэн хүсэлтээс нэг нь амжилттай, нөгөө нь
  `transfer_already_pending` алдаатай. Нэг pending хүсэлт үлдэж, амжилттай
  хүсэлтийн очих байгууллага хэвээр; дахин илгээхэд ижил ID буцна.
- Хүсэлт үүссэний дараа эх эсвэл очих байгууллагыг түдгэлзүүлэх, устгалын
  хуваарьт оруулах дөрвөн тохиолдолд батлах оролдлого
  `transfer_organisation_unavailable` алдаатай. Эх гишүүнчлэл идэвхтэй,
  шинэ гишүүнчлэл үүсээгүй, хүсэлт pending хэвээр, шийдвэрийн аудит үүсээгүй.
- Байгууллагын төлөвийг сэргээсний дараа тухайн хүсэлтийг баталж болно:
  эх гишүүнчлэл идэвхгүй, очих гишүүнчлэл идэвхтэй болно.

Эдгээр тохиолдолд одоогийн хэрэгжилт зөв ажиллав. Runtime код болон schema-д
засвар шаардагдаагүй; тест ба аудитын баримт нэмэгдсэн.

## Үлдсэн ажил

Өмнөх аудитын өөрийгөө батлах боломж, хүний нэр/email болон гишүүнчлэлийн
өөрчлөлтийн үеийн UUID/түүхийн шалгалт, event/оноо/хураамжийн үлдсэн
тохиолдлуудыг дараагийн багцад шалгана. P0 шинэ боломжууд энэ өөрчлөлтөд
хэрэгжээгүй. Хураамжийн бодит дүрэм, ажилтны томилгоо, төхөөрөмжийн
хүлээн авалтын мэдээлэл өмнөх ажлын тэмдэглэлд хүлээгдэж буй хэвээр.

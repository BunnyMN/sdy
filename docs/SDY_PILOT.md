# SDY эхний хэрэглэгчдийн туршилт

Энэ баримт Android/iPhone-ийн бодит хүлээн авалт болон байгууллагын
тохиргооны ажлыг бүртгэнэ. Автомат тестийн амжилт нь бодит утсан дээрх
eID Mongolia нэвтрэлт амжилттай болсны нотолгоо биш.

## 1. Утаснаас бүрэн урсгал шалгах

Android Chrome, iPhone Safari дээр доорх урсгалыг тус бүр шалгана.
Шинэ хэрэглэгч өөрийн eID Mongolia апп-аар өөрөө танилтаа баталгаажуулна.
Нууц үг, OTP, регистрийн дугаарыг туршилтын баримтад бичихгүй.

| Алхам | Үйлдэл | Хүлээгдэх үр дүн |
| --- | --- | --- |
| 1 | `https://e-sdy.mn/member` нээж eID-ээр нэвтрэх | eID апп-аас буцаж гишүүний нүүр нээгдэнэ; давхар хэрэглэгч үүсэхгүй |
| 2 | Android: Chrome цэс → Install app; iPhone: Share → Add to Home Screen | SDY icon нүүр дэлгэцэд нэмэгдэж, түүгээр нээхэд гишүүний нүүр эсвэл нэвтрэх дэлгэц гарна |
| 3 | Суулгасан апп дотроос гараад eID-ээр дахин нэвтрэх | eID апп болон browser/PWA хооронд буцаж ирээд нэвтэрсэн төлөвт орно |
| 4 | Өөрийн сумыг сонгож хүсэлт өгөх | Хүлээгдэж буй хүсэлт харагдана; батлагдахаас өмнө байгууллагын хувийн өгөгдөл нээгдэхгүй |
| 5 | Тухайн сумын manager/admin хүсэлтийг батлах | Зөвхөн өөрийн байгууллагын хүсэлтийг шийдвэрлэж чадна; manager эрх томилж чадахгүй |
| 6 | Гишүүн нүүрээ шинэчлээд салбар руу орох | Зөв сум, арга хэмжээ, өөрийн ирц ба хураамжийн цэс нээгдэнэ |
| 7 | Manager/admin туршилтын арга хэмжээ үүсгэж гишүүн бүртгүүлэх | Энгийн гишүүн арга хэмжээ үүсгэж/засаж чадахгүй |
| 8 | Manager-ийн гаргасан хүчинтэй QR-ийг уншаад ирцээ батлах | Нэг ирц, тохируулсан оноо бүртгэгдэнэ; ижил QR-ээр дахин батлахад давхар оноо үүсэхгүй |
| 9 | Нэвтрээгүй хөтчөөс хүчинтэй QR унших | Нэвтрэлтээс буцаж ирцийн дэлгэцэд очно; хугацаа дууссан эсвэл өөр хөтөч нээгдсэн бол шинэ QR уншуулна |
| 10 | Сүлжээг салгаад дахин нээх, дараа нь холбох | Offline мэдэгдэл харагдана; илгээгээгүй ирц/төлөлтийг батлагдсан гэж үзүүлэхгүй; сүлжээ сэргэхэд үргэлжилнэ |
| 11 | Гараад апп-аа дахин нээх | Өмнөх хүний хувийн мэдээлэл нээгдэхгүй |

QR-ийг өөр дэлгэц дээр харуулж камераар уншуулна. Туршилтын event-д
бодит оноо олгох дүрэм батлагдаагүй бол 0 оноо ашиглана. Хуучин event эсвэл
бодит гишүүний түүхийг туршилтын зорилгоор өөрчлөхгүй.

| Төхөөрөмж | OS / browser хувилбар | eID-аас буцах | Суулгасан апп | Элсэлт → QR | Төлөв |
| --- | --- | --- | --- | --- | --- |
| Android | бөглөх | шалгаагүй | шалгаагүй | шалгаагүй | Хүлээгдэж байна |
| iPhone | бөглөх | шалгаагүй | шалгаагүй | шалгаагүй | Хүлээгдэж байна |

Алдаа гарвал алхмын дугаар, цаг (Улаанбаатар), төхөөрөмж/хөтчийн хувилбар,
харагдсан алдааны текстийг тэмдэглэнэ. Нэвтрэх token, QR-ийн нууц кодыг
баримтад хуулж хадгалахгүй.

## 2. Харьяалал ба хариуцсан хүмүүс

2026-09-11-ний production шалгалтаар Дархан-Уул аймаг болон доорх дөрвөн
сум идэвхтэй. Тус бүрд одоогийн аймгийн админ эрхтэй нэг гишүүн байна;
manager томилоогүй. Parent холбоос нь сумдын хувийн мэдээлэл унших эрх
автоматаар өгдөггүй.

| Сум | Manager-ийн бүртгэлтэй email | Санхүүгийн ажилтны бүртгэлтэй email |
| --- | --- | --- |
| Дархан | өгөх | өгөх |
| Орхон | өгөх | өгөх |
| Шарын гол | өгөх | өгөх |
| Хонгор | өгөх | өгөх |

Томилохын өмнө хүн eID-ээр нэвтэрч бүртгэлээ үүсгэсэн байна. Email эсвэл
системийн user ID-г бодит бүртгэлтэй тулгаж, зөв байгууллагад эрх олгоно.
Менежер хүсэлт шийдвэрлэж, арга хэмжээ удирдана. Санхүүгийн ажилтанд
`membership.finance`-тай тусдаа role хэрэглэж болно; бүтэн admin эрх заавал
шаардлагагүй. Менежер санхүүгийн эрхийг автоматаар авахгүй.

Дараах шийдвэрүүдийг эзэмшигчээс авсны дараа харьяаллын дүрмийг хэрэгжүүлнэ:

- Нэг хүн нэг үндсэн сумтай байх уу, олон сумд гишүүн байж болох уу.
- Аймгийн байгууллагад шууд гишүүнээр элсэх эсэх.
- Сум солих хүсэлтийг хуучин/шинэ сумын хэн батлах, хэзээнээс хүчинтэй болох.
- Шилжсэн хүний өмнөх оноо, төлөлтийг өөрт нь хэрхэн харуулах, сумдын
  тайланд ямар хугацаагаар тооцох.

Үндсэн сумын гишүүнчлэл болон ажилтны олон байгууллагад ажиллах эрх нь
тусдаа ойлголт. Нэг үндсэн сумтай болгохын тулд админы бусад байгууллагын
ажиллах эрхийг устгахгүй. Одоогийн платформ олон байгууллагын гишүүнчлэл
дэмждэг; нэг үндсэн сум, сум хооронд шилжилтийн урсгал хараахан хэрэгжээгүй.

## 3. Хураамж, онооны бодит тохиргоо

2026-09-11-ний шалгалтаар хураамжийн тохиргоо үүсээгүй, идэвхжээгүй.
Бодит ногдуулалт хийхийн өмнө доорх утгуудыг байгууллага бүрээр эсвэл
дөрвөн сумд ижил үйлчлэхээр өгнө.

| Тохиргоо | Хэрэгтэй утга | Одоогийн боломж |
| --- | --- | --- |
| Сарын хураамж | Бүхэл төгрөгийн дүн | Салбар тус бүрийн тохиргоо |
| Төлөх эцсийн өдөр | Сарын 1–28-ны өдөр | Сарын ногдуулалтын хугацаа |
| Хүлээн авагч | Банк, дансны дугаар, данс эзэмшигч | Гишүүнд шилжүүлгийн заавар харуулна |
| Эхлэх сар | `YYYY-MM` | Санхүүгийн ажилтан сонгосон сараа нэг удаа ногдуулна |
| Элссэн эхний сар | Бүтэн, дараа сараас, эсвэл хувьчилж тооцох | Хувьчилсан автомат тооцоо одоогоор байхгүй |
| Чөлөөлөх дүрэм | Хэн, ямар үндэслэлээр, хэдий хугацаанд | Шалтгаантай нэг ногдуулалтын үлдэгдлээс чөлөөлнө; давтамжтай автомат чөлөөлөлт байхгүй |
| Event-ийн оноо | Төрөл тус бүрийн ирцийн оноо | Event үүсгэхэд 0–100000; анхдагч 0 |

Идэвхтэй гишүүнчлэлд ногдуулна; идэвхгүй хүний хуучин өр, төлөлтийг
арилгахгүй. Нэг хүний олон салбарын гишүүнчлэл тус бүрд төлбөр ногдох
боломжтой тул үндсэн сумын дүрмийг шийдэхээс өмнө дөрвөн сумд бөөнөөр
ногдуулалт хийхгүй.

Бодит дүн, данс болон дүрэм ирэхэд тохиргоог хадгалж, тохирсон эхлэх сарын
ногдуулалтыг шалгана. Гишүүний мэдээлсэн шилжүүлгийг банкны хуулгатай
тулгасан санхүүгийн ажилтан батална. Гүйлгээний дугаар оруулах нь банкнаас
төлбөр амжилттай болсон гэсэн автомат баталгаа биш.

Хүлээн авахад: зөв гишүүний дүн/хугацаа/данс, хэсэгчилсэн төлөлт ба үлдэгдэл,
давхар ногдуулахгүй байх, татгалзалт/залруулгын түүх, өөр гишүүний мэдээлэл
харагдахгүй байх, manager санхүүгийн эрхгүй үед баталж чадахгүйг шалгана.
